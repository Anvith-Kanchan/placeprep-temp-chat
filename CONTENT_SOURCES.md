# Content research & source map

RoundZero uses short, independently authored explanations and prompts. The references below informed the topic sequence, terminology and further-reading links. They are not presented as endorsements, partnerships or ownership of the linked material.

| Area | Reference | How it is used |
|---|---|---|
| Overall placement preparation | [takeUforward Prep Hub](https://takeuforward.org/prep-hub) | Subject grouping, progression from in-depth learning to interview preparation, and the idea of keeping DSA and core CS visible together. |
| Core CS interview questions | [GeeksforGeeks technical interview preparation](https://www.geeksforgeeks.org/technical-interview-preparation/) | Topic coverage cross-check for OS, CN, DBMS, OOP and general interview practice. |

| HTTP and web delivery | [MDN — Overview of HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview) and [How the web works](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works) | Browser request flow, HTTP semantics, connections, proxies and DNS context. |

## Interview and assessment flow

The application tracker models a common, deliberately generic path: resume/shortlist → online assessment → technical rounds → design or manager discussion → HR/offer. This is a preparation framework, not a universal employer process. Some employers combine stages, omit design rounds, add aptitude or debugging tasks, or change the order. The product therefore lets the candidate update each application's stage rather than hard-coding one process.

## Editorial notes

- Lesson explanations are concise paraphrases written for this project, not scraped article text.
- Interview prompts are independently authored around commonly tested concepts; they are not labelled as exact questions asked by a particular employer.
- External links point to their publishers and may change over time.
- The Oracle Java tutorial is an older JDK 8-era tutorial; Dev.java is included as the more current Java learning starting point.
- The practice assessment is original and illustrative. It is not affiliated with HackerRank, CodeSignal, TUF, GeeksforGeeks or any employer.
